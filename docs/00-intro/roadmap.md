## 最短路径：尽快跑起来

只想尽快用上的话，按这个顺序走：

1. [认识终端](../01-environment/terminal)：学会打开终端、输入命令
2. [安装 Node.js 与 npm 镜像](../01-environment/nodejs)：这是安装两个工具的前提
3. [安装 Git](../01-environment/git)：Agent 改代码时，Git 是你的"后悔药"
4. [安装 Claude Code](../03-claude-code/) 或 [安装 Codex CLI](../04-codex/)
5. [准备 DeepSeek API Key](../05-deepseek/)，然后看对应工具的接入页
6. 回到 [Claude Code 第一次上手](../03-claude-code/basics) 或 [Codex 第一次上手](../04-codex/basics)，完成第一个任务

::: tip 为什么安装和上手之间要先跳到第 5 章？
工具装好之后，必须先接入一个模型才能用。第 3、4 章讲工具本身，第 5 章讲接入 DeepSeek，所以实际操作顺序是：**安装 → 接入模型 → 上手**。
:::

做完第 6 步，你就可以在自己的电脑上用 AI 写代码了。

## 我该选 Claude Code 还是 Codex？

两个都很好，**接入 DeepSeek 后用的是同一个模型**，区别主要在交互体验和生态。

| 如果你…… | 建议 |
|---|---|
| 纠结不知道选哪个 | 先学 **Claude Code**。本教程的 Skill 章节以它为主，中文社区资料也更多 |
| 以后打算用 ChatGPT 订阅 | 选 **Codex**，可以直接用订阅额度 |
| 想都试试 | 两个都装。它们互不冲突，配置文件也分开存放 |

## 本教程的约定

**代码块**：灰色背景的框里是要输入的命令或文件内容。右上角有复制按钮，建议直接复制，不要手打。

**系统切换**：同一个操作在不同系统下命令不同时，会用标签页区分，点击切换：

::: code-group
```powershell [Windows]
# Windows 下的命令
```

```bash [macOS / Linux]
# macOS 或 Linux 下的命令
```
:::

**尖括号占位符**：`<你的 API Key>` 这种写法表示"把整个尖括号连同里面的文字，替换成你自己的内容"。例如 `<你的 API Key>` 要替换成 `sk-abc123...`，**尖括号也要删掉**。
