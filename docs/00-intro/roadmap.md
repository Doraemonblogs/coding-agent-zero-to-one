## 我该选 Claude Code 还是 Codex？

两个都很好。**接入 DeepSeek 之后，它们背后用的是同一个模型**，区别主要在交互方式和生态。

| 如果你…… | 建议 |
|---|---|
| 纠结不知道选哪个 | 先学 **Claude Code**。它默认每一步都先问你，更适合新手观察和学习；中文社区的资料也更多 |
| 以后打算用 ChatGPT 订阅 | 选 **Codex**，可以直接用订阅额度 |
| 想都试试 | 两个都装。它们互不冲突，配置文件也分开存放 |

两者的主要区别：

| | Claude Code | Codex CLI |
|---|---|---|
| 默认怎么把关 | 修改文件、执行命令前**先问你** | 在项目文件夹内**直接修改**，越界时才问你（沙箱机制） |
| 项目说明文件 | `CLAUDE.md` | `AGENTS.md` |
| Skill 放在哪 | `~/.claude/skills/` | `~/.agents/skills/` |
| 接入 DeepSeek 的方式 | 改 `settings.json` | 改 `config.toml` + 设置环境变量 |

## 本教程的约定

### 页面顶部的标签

每页标题下方有一排小标签：

- **预计用时**：跟着做一遍大约需要的时间；
- **最后验证**：作者最后一次按步骤检查这一页的日期；
- **工具版本**：验证时使用的软件版本。你的版本更新时，界面可能略有不同；
- **已实测 / 部分待实测 / 待实测**：作者是否在真实环境中跑通了这一页的步骤。

### 代码块和系统切换

灰色背景的框里是要输入的命令或文件内容。右上角有**复制按钮**，建议直接复制，不要手打。

同一个操作在不同系统下命令不同时，会用标签页区分，点击切换：

::: code-group
```powershell [Windows]
# Windows 下的命令
```

```bash [macOS / Linux]
# macOS 或 Linux 下的命令
```
:::

### "你会看到"

深色窗口展示的是**命令执行后正确的输出**，用来和你屏幕上的结果对照：

::: terminal 你会看到
```text
v24.21.0
```
:::

版本号等细节和你看到的不完全一样是正常的，只要格式对得上就行。

### 按键

<kbd>Ctrl</kbd> + <kbd>C</kbd> 表示先按住 <kbd>Ctrl</kbd>，再按 <kbd>C</kbd>。

::: tip macOS 用户注意
在**终端和 Agent 里**，<kbd>Ctrl</kbd> 快捷键在 macOS 上也是按 <kbd>Control</kbd> 键，不是 <kbd>Command</kbd>。复制、粘贴这类图形界面操作，教程会分别写明两个系统的按键。
:::

### 尖括号占位符

`<你的 API Key>` 这种写法表示"把整个尖括号连同里面的文字，替换成你自己的内容"。例如 `<你的 API Key>` 要替换成 `sk-abc123...`，**尖括号也要删掉**。

### 遇到和教程不一样的情况

软件更新很快。如果你按步骤操作时发现界面、文字和教程不一样：

1. 先以你看到的**实际界面**为准，找意思相近的选项；
2. 查看 [常见问题](../faq/)；
3. 还解决不了，欢迎到 GitHub 提 Issue，附上你的系统版本、工具版本和截图。
