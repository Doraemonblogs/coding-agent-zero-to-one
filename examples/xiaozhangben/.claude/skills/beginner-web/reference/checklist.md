# 功能完成前的检查清单

逐项检查，发现问题先修复，再告诉用户完成了。

## 功能

- [ ] 用户描述的每一项需求都实现了
- [ ] 输入为空、输入特别长、输入非数字等情况不会让页面出错
- [ ] 刷新页面后，应该保存的数据还在（使用了 localStorage 时）

## 代码

- [ ] 用 `node --check app.js` 检查 JavaScript 没有语法错误
- [ ] 没有留下调试用的 `console.log`
- [ ] HTML 里引用的文件名（`style.css`、`app.js`）和实际文件名一致

## 界面

- [ ] 电脑宽屏下布局正常
- [ ] 手机窄屏（375px）下没有横向滚动条，文字不重叠
- [ ] 按钮有明显的点击反馈（悬停或按下时颜色变化）
