# 新手网页项目规范

用户是编程新手。制作或修改网页时，遵守以下规范。

## 技术选择

- 只用原生 HTML、CSS、JavaScript，**不要**引入框架、构建工具或需要 `npm install` 的依赖。
- 项目结构保持简单：`index.html`、`style.css`、`app.js` 三个文件即可，放在项目根目录。
- 需要保存数据时，用浏览器的 `localStorage`，不要引入数据库或后端服务。
- 不要使用需要联网才能加载的外部资源（CDN 字体、图片、脚本），保证断网也能打开。

## 代码风格

- 代码注释用简体中文，重要的函数上方写一行注释说明它做什么。
- 变量和函数名用英文，名字要能看出含义（`totalAmount`，而不是 `a1`）。
- 界面上的文字用简体中文。

## 界面

- 页面在手机（宽度 375px）和电脑上都要正常显示，不出现横向滚动条。
- 字体大小不小于 14px，按钮和可点击区域不小于 40px 高。
- 颜色有足够的对比度，文字清晰可读。

## 每次改动后

1. 用一两句话告诉用户改了什么。
2. 告诉用户怎么查看效果：直接用浏览器打开 `index.html`，或者刷新已经打开的页面。
3. 如果改动较大，提醒用户可以用 Git 存一次档。
