# 小账本

一个在浏览器里运行的个人记账网页，给自己日常使用。不用安装、不用联网、不用注册，打开就能记账。

## 功能

- **记一笔**：选择收入或支出，填写金额、分类、日期（默认今天）、备注（可不填）
  - 支出分类：餐饮、交通、购物、娱乐、学习、居住、其他
  - 收入分类：工资、兼职、红包、其他
- **本月汇总**：一眼看到当前月份的总收入、总支出、结余
- **支出分类占比**：用横条图显示本月各分类支出的百分比，从高到低排列
- **明细列表**：按日期分组、新的在上面，每条可以删除（删除前会确认）
- **切换月份**：点「‹ 上月」「下月 ›」查看任意月份的账目
- **自动保存**：每记一笔都存进浏览器里，刷新页面、关闭再打开，数据都还在

## 怎么打开使用

1. 在文件夹里找到 `index.html`
2. **双击它**，浏览器就会打开小账本
3. 想放在手机上用？把整个文件夹拷到手机里，用手机浏览器打开 `index.html` 即可

不需要安装任何软件，也不需要联网。

## 数据存在哪里

你的每一笔记账都保存在**「这台电脑的这个浏览器」**里（浏览器的 localStorage），不会上传到任何地方，断网也能正常使用。

**请注意：**

- 换了浏览器、换了电脑，或者清除了浏览器数据（历史记录、Cookie、网站数据等），记账记录就会**丢失**，请提前留意
- 想长期保存账目，建议定期把重要数据抄录或导出备份（导出功能暂未提供）

## 项目结构

```
index.html  页面结构
style.css   样式
app.js      记账逻辑
PLAN.md     开发计划与进度记录
```

只用原生 HTML/CSS/JavaScript 写成，没有任何框架和依赖。
