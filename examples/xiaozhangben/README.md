# 小账本（参考成品）

教程 [第 7 章 · 实战项目](../../docs/07-practice/index.md) 的参考成品：一个在浏览器里运行的个人记账网页。

- 记录收入和支出，按月汇总，显示支出分类占比
- 数据保存在浏览器的 localStorage 中
- 只用原生 HTML / CSS / JavaScript，双击 `index.html` 即可使用

> 这份代码由教程作者编写，用来展示第 7 章最终应该达到的效果，并经过浏览器自动化测试（表单校验、增删记录、刷新后数据保留、月份切换、手机宽度无横向滚动）。你用 Agent 做出来的版本，代码细节和它不同是完全正常的。

**注意**：清除浏览器数据会删除所有记录。
