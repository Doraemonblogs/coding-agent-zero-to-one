## 运行方式说明

为了能逐步记录耗时和用量，作者用 Claude Code 的非交互模式（`claude -p ... --continue`）依次发送教程里的每一句话，效果等同于在同一个对话里连续输入。和教程的建议有两处不同：

- 编辑文件使用了 `acceptEdits` 模式（自动批准文件修改），并预先允许了 `git`、`node`、`ls`、`cat` 命令。**你自己操作时，建议按教程用 Manual 模式逐个查看、批准。**
- 每个阶段结束后，由作者的自动化脚本代替人工在浏览器里验收（见下文「验收结果」）。

## 大概花了多少钱

按 [DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)（deepseek-v4-pro，2026-09）估算：

- 空闲时段：约 **1.96 元**
- 高峰时段（工作日 9:00-12:00、14:00-18:00）：约 **3.92 元**
- 如果没有缓存（全部按未命中计价，空闲时段）：约 25.5 元

输入内容中有 **98.9%** 命中了 DeepSeek 的缓存，这是费用这么低的主要原因。

> 以上金额由 Claude Code 报告的 token 数乘以官方单价估算，实际扣费以 DeepSeek 开放平台的账单为准。

## 值得注意的地方

- Agent 在阶段 4 按 `beginner-web` 的检查清单**自己发现并修复了一个 bug**：日期被清空时会存入一条哪个月都看不到的记录。
